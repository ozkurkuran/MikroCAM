# Interlace demo

Özgün sentetik devre çizimi; gerçek kart/üretim reçetesi değildir. `demo.svg`30×18 mm,
`master.png`600×360 px,508 DPI. `demo-interlace-N3.zip` içinde3adet600×3601-bit grupPNG,
taşınabilirjob.json ve manifest var. Birleşim ana maskeye birebir eşit; her piksel bir
grupta. `combined-preview.png` yalnız açıklayıcı renkli önizlemedir.

Bu ZIP native LightBurn projesi değildir. Sıra/konum bilgisi manifest içindedir;
LightBurn katmanları, güç/hız ve bekleme uygulanmış sayılmaz. Gerçek profil doğrulaması
bekleniyor. Kaynağın/ana maskenin siyah alanları hedef kazıma alanıdır.
