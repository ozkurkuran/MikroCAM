# Dependency notices added by the baseline slice

These notices are copied verbatim from installed wheel metadata for the pinned versions.
Package README files identify the source version. pytest and pytest-qt are new development
tools, both MIT. svgtrace and install-playwright are MIT; Playwright is Apache-2.0 and is an
optional image-tracing dependency already reached through Evo's svgtrace dependency.

The application license does not replace dependency licenses. This directory is the
incremental baseline record, not the complete distribution notice bundle. In particular,
PyQt6 remains GPLv3/commercial licensed as supplied by its upstream; the complete dependency
inventory and distribution notices are the separate branding-and-notices roadmap slice.
