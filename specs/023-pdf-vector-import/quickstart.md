# Quickstart: selected PDF vectors

Use the pinned Python3.13 environment after installing requirements.txt including pypdf6.19.0.
Run focused PDF reader/model/geometry/bridge/UI tests and existing PDF/SVG regressions, then
the complete `python -m pytest -q` and real desktop `python tests/smoke_app.py`.

File → Import → PDF vector page opens the new workflow. Choose a PDF, inspect pages, choose one
page and CropBox/MediaBox. Optionally enter a physical crop and enable vertical flip. Analyse,
review bounds and source facts, name and explicitly create the Geometry. Export/reparse and
project save/reopen without the input file retain physical geometry, exact source and report.
Changes to file or options require another review. Unsupported visible content fails clearly.

The legacy PDF tool remains independently available. This workflow does not infer drills,
outline text, rasterize artwork or connect manufacturing equipment.
