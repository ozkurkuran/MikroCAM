# Source detection contracts

## Public core API
mikrocam.core.cad_source exposes CAD_APPLICATIONS, CadSourceEvidence and CadSourceAssessment
with fields/strict invariants in data-model.md. cad_source_codec exports source_to_dict(record)
and source_from_dict(value), SOURCE_SCHEMA_VERSION=1, MAX_SOURCE_REPORT_BYTES=65536.

## Pure inspection API
mikrocam.importers.cad_source.detect_cad_source(source:bytes, source_name:str,
source_format:str)->CadSourceAssessment. Caller type/name/format errors raiseValueError;
source parse/encoding/budget limitations returnUnknown/unavailable, never a partial identification.
Bytecap16MiB (MAX_CAD_SOURCE_BYTES); within cap SHA256 over exact bytes even if malformed; above
cap shaNone. Name not a classification input. SVG/DXF explicit format argument, no extensionguess.
Shared importers/cad_producer.py exports classify_producer(value:str)->str and
producer_declaration(value:str)->str|None (extracts the declared producer after anchored
Generator: / Creator: / Created with / Generated by / Image generated by, case-insensitive).
The classifier recognizes anchored KiCad/PCBNEW/Eeschema, Adobe Illustrator/
Illustrator, Inkscape, Labcenter Proteus/Proteus with name boundaries and optional version suffix.
Unsupported/ambiguous producer values yieldUnknown; no broad substring matching or score.
assessment construction deduplicates identical evidence in encounter order; >32 raises internal
ValueError captured asunavailable, not identified from a truncated set. Multiple applicationclaims
including unsupportedproducer mixedwithknown areconflicting; onlyUnknownclaim/noevidence unknown.

## SVG evidence
cad_svg_source.svg_source_evidence(source:bytes)->tuple[CadSourceEvidence,...]. UTF8/BOM only,
XML elementbudget10000/depth64; complete valid SVGroot, no external reads. Entity/internal DTD
reject; only fixed PUBLIC -//W3C//DTD SVG 1.1//EN with http://www.w3.org/Graphics/SVG/1.1/DTD/svg11.dtd
is accepted by the offline XML parser after declaration validation. It is never fetched; complete
XML framing still applies, so a DTD inside the root is invalid. Geometry importer policy is unchanged.
- Root attribute expanded {http://www.inkscape.org/namespaces/inkscape}version with version-number
  syntax -> Inkscape, fieldsvg.inkscape.version. A namespace declaration alone isnot evidence.
- Expanded {http://ns.adobe.com/xap/1.0/}CreatorTool attribute/simpleelement under directroot
  SVG/unnamespaced metadata -> classify declared value, fieldsvg.xmp.CreatorTool. Nested metadata subtrees are pruned. Foreign metadata,
  drawing text, id, filename, title, arbitrary attrs and generic MaxPageSize ignored.
- Directroot SVGdesc with anchored Image generated by / Generated by / Created with producer
  declaration -> fieldsvg.desc; original full value retained, classify only declared producer.
  Post-delivery genuine-sample fix (2026-10-04): desc_declaration(value) additionally admits anchored
  Created by only when the declared value classifies to a supported application (observed genuine
  Proteus export: Created by Proteus Design Suite). Not admitted in comments or DXF999. Proteus name
  grammar accepts optional Labcenter prefix and Design Suite suffix.
- Document-prolog or directroot XMLcomments with anchored Generator: / Creator: / Created with /
  Generated by -> fieldsvg.generator-comment; generator declarations in artwork/metadata ignored.

## DXF evidence
cad_dxf_source.dxf_source_evidence(source:bytes)->tuple[CadSourceEvidence,...]. ASCII/UTF8BOM text
DXF complete code/value pairs, <=250000pairs/8192charline, integercode0..1071, well-formed SECTION/
ENDSEC framing and final0EOF. Binary/otherencoding/malformed input unavailable. No entity geometry.
Only999comments outside sections orinsideHEADER, with anchored Generator: / Creator: / Created with /
Generated by declare producer, fielddxf.999. Whole original comment retained. Entity TEXT/MTEXT,
STYLE/APPID values, $ACADVER/$LASTSAVEDBY/$INSUNITS and unstructured vendor mentions ignored.
