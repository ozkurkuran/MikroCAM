# Research: explicit CAD producer evidence

## Decision and rationale
Use finite declared producer fields, never geometry/filename/layer/profile scoring. Metadata can
be copied and may describe the first tool rather than the last exporter; present it as a claim.
Conflicting applications produce Unknown, retaining the evidence. Unknown is useful information.
Rejected alternative: Neo scores names, style tables, layer/profile and geometric signals; these
cannot establish provenance and would misclassify copied artwork. No Neo source module copied.

## Primary references
- [Adobe XMP Basic](https://developer.adobe.com/xmp/docs/xmp-namespaces/xmp/): exact namespace
  http://ns.adobe.com/xap/1.0/ and CreatorTool field; it describes first-known creating tool.
- [Inkscape SVG](https://wiki.inkscape.org/wiki/InkscapeSVG): editor-specific metadata.
  A mere namespace declaration is not evidence; root expanded inkscape:version is.
- [KiCad SVG output](https://docs.kicad.org/doxygen/SVG__plotter_8cpp_source.html): direct root desc
  identifies m_creator. Inspected output format only; no GPL implementation code ported.
- [Autodesk DXF group codes](https://help.autodesk.com/cloudhelp/2018/ENU/AutoCAD-DXF/files/GUID-3F0380A5-1C15-464D-BC66-2C5F094BCFB9.htm):999 is a comment,9 a HEADER variable.
  Comments count only when explicit generator/creator declaration syntax is present; format revision,
  INSUNITS, application tables and KICAD font styles do not identify the exporting application.
- MIT Neo head914630319725b0d6034801f4808ae345d53b407b,
  DXFSourceDetector.py commit7b3ea49f96174a38dd079fba7574982b6ec6f1c4;

## Persistence and limits
Use separate optional schema1 source assessment because current physical ImportReport is SVG-only.
Old absence isNone, invalid data becomes visible unavailable; never recompute on Properties display.
Inspection caps return Unknown/unavailable with reason and optional hash; unsupported binary/encoding
is diagnostic, not a geometry-parser change. Only fixed SVG1.1 external DOCTYPE syntax is admitted
for source inspection; entity declarations/internal subsets/other DTDs are unavailable, no network.
