# Quickstart
Use pinned Python 3.13. Run the focused `test_dry_run` modules, the full pytest suite, and a desktop
smoke test.

From a successful original preflight, choose **Dry run**, enter an explicit machine Z, and select
**Prepare**. Review the derived identity, bounds, time, and lineage. Then load it into Machine,
confirm the mechanical-job prompt, and select **Start**.

Validation uses Fake only. Verify the first move is upward in Z, output start is absent, and pause,
stop, and close behavior works. Physical clearance remains operator-declared; these tests do not
certify collision avoidance or physical output-off behavior.
