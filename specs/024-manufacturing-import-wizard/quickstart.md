# Quickstart: manufacturing file set

Open File → Import → Production file set. Drop local Gerber/Excellon files into the dialog or
choose several files. Inspect them, review format/layer/unit evidence, resolve unknown/conflicting
roles, select desired rows and give distinct output names. Review selected files, then import.

Watch per-file outcomes. Completed rows are retained and locked; a failed row stops later imports.
Fix/review remaining rows before retrying. Classification does not mirror bottom copper, align
boards or change coordinates. Each file uses normal parsing, unit conversion and factory defaults.

Save/reopen the project without original files: the separate objects retain exact source and
historical layer reports. Old projects without these reports still load. Test the authored mixed
set, existing real corpus classifications, full pytest suite and real desktop drop/project journey.
